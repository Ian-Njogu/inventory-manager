# Inventory Management System

This is a simple inventory management system built using vanilla JavaScript. It allows you to add, remove, and filter items, and it displays the total inventory count. It uses functional programming concepts like `map()`, `filter()`, and `reduce()` to transform and manage inventory data.

## Features

- **Add Items**: You can add items to the inventory with a name and quantity.
- **Remove Items**: You can remove one or more items from the inventory.
- **Filter Items**: Filter items by a minimum quantity.
- **Inventory Display**: The current inventory and total count are displayed dynamically.
- **Functional Programming**: Utilizes `map()`, `filter()`, and `reduce()` to manage the inventory efficiently.

## How to Use

### 1. Add Items to the Inventory
- Enter the item name in the input field (e.g., "apple").
- Enter the quantity (e.g., 5).
- Click **Add** to add the item to the inventory.

### 2. Remove Items from the Inventory
- Enter the item name(s) (e.g., "apple, banana") in the input field.
- Click **Remove** to remove the items from the inventory.

### 3. Filter Items by Quantity
- Enter a minimum quantity value (e.g., 5).
- Click **Filter** to show only items with a quantity greater than or equal to the entered value.

### 4. View Total Inventory
- The system will automatically update the total inventory count as you add or remove items.
